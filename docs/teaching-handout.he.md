# JenAI Studio - דף לסדנה

מערכת AI לתמונות וסרטונים
שרצה על המחשב שלך

## מה זה

אפליקציה קטנה שרצה אצלך על המחשב
מייצרים בה תמונות וסרטונים עם המפתח שלך
בלי אתר באמצע בלי מנוי

## לפני הסדנה

מתקינים שני דברים
Node מהאתר nodejs.org
Git

ונרשמים לספק אחד בשביל קרדיטים חינם
Oxen.ai - נכנסים ל-oxen.ai ושולחים מייל ל-hello@oxen.ai בשביל $40
או Kie.ai - נכנסים ל-kie.ai ומקבלים 80 קרדיטים

שומרים את המפתח בצד

## בסדנה

דבר ראשון
אומרים ל-Claude שלכם
תתקין לי את JenAI Studio

Claude מוריד מריץ ופותח את האפליקציה על localhost

יש לכם אתר שרץ על המחשב שלכם

## מדביקים מפתח

בפופאפ שנפתח בוחרים ספק ומדביקים את המפתח
או מדלגים ומסתכלים מסביב

הולכים לטאב תמונות
